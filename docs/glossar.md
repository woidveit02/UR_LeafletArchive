# Glossar

| Begriff | Bedeutung |
|---|---|
| **Band** | Ein digitalisierter Archivkarton als PDF, z. B. `0118_0003`. Entspricht einer Verzeichnungseinheit. |
| **Verzeichnungseinheit** | Einheit im Findmittel des Archivs, hier ein Karton. |
| **Findmittel** | Verzeichnis des Archivs zum Bestand Rep. 118. Geführt in der Archivsoftware ACTApro, exportiert im Austauschformat HIDA-DOC1-XML (Schema aus HiDA von startext). |
| **Segment** | Zusammenhängende Seitenfolge eines Bands, die beim Trennen als ein Flugblatt bestimmt wurde. |
| **Leerseite** | Seite ohne Inhalt, etwa eine leere Rückseite oder ein Trennblatt. Gehört beim Trennen zu keinem Flugblatt. |
| **Entwurf** | Ein Band, der gerade eingelesen wird. Er ist nur im Import und in der Verwaltung zu sehen, nicht in Liste, Suche, Trends und Themen. |
| **Freigabe** | Der letzte Schritt des Imports. Danach erscheint der Band in Liste, Suche und Trends. Sie lässt sich zurücknehmen. |
| **Prüfhinweis** | Hinweis der App, dass eine erzeugte Angabe (Datum, Beleg, Herausgeber) nicht so im erkannten Text steht. Wird in Schritt 6 korrigiert oder mit „Passt so“ bestätigt. |
| **Vz-Nummer** | Nummer der Verzeichnungseinheit, also des Bandes, im Findmittel. In der Anwendung die Adresse eines Bandes (`/volumes/6`). |
| **Embedding** | Zahlenvektor, der den Inhalt eines Textes so darstellt, dass ähnliche Texte nahe beieinander liegen. Grundlage der Themen. |
| **Flugblatt** | Wie im Namen der Sammlung: jedes Stück des Bestands, also auch Einladung, Broschüre usw., und ein Datensatz im Korpus. Mehrere Exemplare zählen als ein Flugblatt. Als Textsorte meint „Flugblatt“ enger das einzelne Blatt mit Aufruf oder Stellungnahme. |
| **Exemplar** | Ein physisches Stück eines Flugblatts. Mehrere Exemplare desselben Blatts sind im Bestand gewollt; im Archiv heißen sie Doppelstücke. |
| **Hauptexemplar** | Das Exemplar, das ein Flugblatt in Liste, Trends und Export vertritt. |
| **Textsorte** | Art eines Flugblatts im weiteren Sinn: Flugblatt (einzelnes Blatt mit Aufruf oder Stellungnahme), Einladung, Broschüre, Offener Brief, Zeitschrift … |
| **OCR** | Optische Zeichenerkennung: Umwandlung der Scans in Text. |
| **Bounding Box** | Rechteck, das die Lage eines Blocks, einer Zeile oder eines Worts auf der Seite angibt. |
| **Block-Typ** | Klassifikation eines erkannten Bereichs, z. B. Überschrift, Text, Tabelle, Bild, Kopfzeile. |
| **Lesereihenfolge** | Reihenfolge, in der die erkannten Blöcke gelesen werden sollen. |
| **Goldstandard** | Von Hand geprüfte Referenzabschrift, gegen die die OCR gemessen wird. |
| **CER / WER** | Zeichen- bzw. Wortfehlerrate gegenüber dem Goldstandard. |
| **Register** | Verzeichnis der Herausgeber (Organisationen) mit kanonischem Namen, Kürzel und Schreibvarianten, aufgebaut aus dem Findmittel; in der Anwendung unter „Herausgeber“. Nicht mit der GND abgeglichen. |
| **GND** | Gemeinsame Normdatei der Deutschen Nationalbibliothek. |
| **Token** | Ein Wort im Sinne der Zählung, nach Tokenisierung. |
| **Keyness** | Maß dafür, wie charakteristisch ein Wort für ein Teilkorpus ist (hier Dunnings G²). |
| **logDice** | Maß für die Stärke einer Kollokation, unabhängig von der Korpusgröße. |
